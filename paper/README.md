# NeuralPOM manuscript

- [arXiv preprint (2611.02460)](https://arxiv.org/abs/2611.02460) · [arXiv PDF](https://arxiv.org/pdf/2611.02460)
- [English paper (repository copy)](NeuralPOM.pdf)
- [Supplementary figures](Supplement.pdf)
- [Chinese version](paper_zh.md)
- [Reference dataset on ModelScope](https://www.modelscope.cn/datasets/chiyodamomo01/NeuralPOM)

The `data/` directory contains the scalar forecast scores, training-stage comparisons, layer profiles, and spectra used in the manuscript. `data/ai_baselines/` contains per-origin, daily, and pooled scores for the AI forecast comparisons. `data/policy_comparisons/` contains the correction-policy comparisons. Column names and units follow the manuscript's definitions.

The `figures/` directory contains the method illustration and figures used by the Chinese version.
